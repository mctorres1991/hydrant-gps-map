HYDRANT GPS - first working version

Open index.html in a browser. The app displays NYC hydrants from the NYC DEP Citywide Hydrants dataset, loads hydrants for the current map area, supports GPS location, nearest shown hydrant, address search, and navigation to a hydrant.

For Android home-screen installation, host these files on HTTPS (GitHub Pages, Netlify, etc.), open the site in Chrome, then choose Add to Home screen / Install app.

Data source: NYC Open Data, NYCDEP Citywide Hydrants (dataset 6pui-xhxz).
Map tiles: OpenStreetMap.
Geocoding: Nominatim.
